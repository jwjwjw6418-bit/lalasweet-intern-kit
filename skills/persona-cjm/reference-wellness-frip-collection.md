## STEP 7. 미확인 목록
- 마이리얼트립 국내 투어(M1~M3)의 후기·상세 일정 — 검색 카드에 후기 표기가 없음. 상세페이지에서 직접 확인
- 네이버 여행/예약의 비슷한 상품 — 미조사
- 후기가 쌓인 '웰니스' 전용 1박 2일 투어 — 두 플랫폼에서 거의 찾지 못함. 템플스테이 공식 사이트(templestay.com) 휴식형 프로그램의 가격·후기로 대체 비교 검토
- 프립 상품 문의(Q&A) — 공개 탭 없음. 호스트 1:1 문의는 볼 수 없으므로, 리뷰 속 "망설임" 원문(STEP 2 추가 표)으로 대체하거나 타겟 인터뷰로 보완
- P2 평점 낮은순 리뷰 — 정렬 결과 첫 10건이 모두 5점으로 표시됨(2차 수집에서 P4는 확인 완료). P2는 98%가 5점이라 낮은 평점 표본 자체가 적음
- P4 전체 스케줄 시간표 — 상세페이지 "스케줄" 영역이 펼쳐지지 않음. 사람이 상세페이지에서 직접 확인
- 네이버 데이터랩 검색어 추이 — 수집 브라우저에서 차단됨. 사람이 datalab.naver.com에서 조회 후 화면 캡처를 data 폴더에 저장
- 인스타그램 해시태그 인기 게시물 — 로그인 필요. 사람이 로그인 후 #주말힐링 등 4개 해시태그 상위 게시물 캡처
- 우수 웰니스관광지 전체 목록 — 한국관광공사 웰니스 관광 공식 페이지에서 원문 목록 확인
- 국내여행 '소비자분쟁해결기준' 취소 시점별 배상 비율 — 공정거래위원회 고시 원문(국가법령정보센터 '소비자분쟁해결기준' 별표) 확인
